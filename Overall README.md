# Pythonia Apartment Booking Management POS System

A Python-based Point of Sale (POS) and apartment booking management system developed for Pythonia Serviced Apartments as part of the RMIT COSC2531 Programming Fundamentals course.

This project contains two assignment implementations that progressively build a complete apartment reservation and management system using both procedural programming and object-oriented programming concepts.

---

# Project Overview

Pythonia is a serviced apartment company managing three apartment buildings:
- Swan
- Goose
- Duck

The system is designed for booking managers to:
- Process apartment reservations
- Manage guests and reward points
- Handle supplementary services
- Generate booking receipts
- Store booking records
- Manage apartment units and bundles

# 1.Procedural POS System

Assignment 1 focuses on:
- Python fundamentals
- Menu-driven programming
- Input validation
- Booking receipt generation
- Reward point calculations
- Supplementary item ordering
- Guest and apartment management

Key features:
- Apartment booking system
- Reward points tracking
- Supplementary services
- Dynamic menu operations
- Guest booking history
- Error handling and validation
